# Quiz 2

### Reflections
After going through the Test Driven Development process, I notice how effective it can be for identifying what's required of a component by unit testing what's expected from it. While the exercise was simple in function, I can see how starting with one test and one implementation can help developers build complex systems by taking small simple steps.
